## 👋 Hey, I'm Musteqeem

I’m a developer and project builder known online as **Future Scientist**. I enjoy creating practical software—from messaging-bot tools and AI-enabled experiences to web projects and reusable developer libraries.

My work is centered around **JavaScript, Node.js, automation, conversational tools, and web development**. I like taking an idea from an early prototype through to something people can explore, run, and improve.

> **My focus:** useful products, approachable open-source projects, and tools that make building easier.

## ✨ What I build

- 🤖 **Messaging and automation projects** — WhatsApp and Telegram bot experiences, management tools, and companion utilities.
- 🧠 **AI-enabled software** — experiments and features for conversational experiences, memory, and helpful automation.
- 📦 **Developer tools and libraries** — reusable building blocks, including my `@musteqeem/baileys` project.
- 🌐 **Web experiences** — portfolio, design, and web utility projects.
